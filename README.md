# Password-manager
This is a basic command-line password manager built using Python. It allows users to store and retrieve passwords for different websites using a simple text file. Passwords are saved in a structured format and can be searched by website name. When a password is retrieved, it is automatically copied to the clipboard using the pyperclip module, making it quick and convenient to use. The project demonstrates core Python concepts such as file handling, loops, conditional statements, and user input handling. This lightweight project is ideal for beginners learning Python and serves as a foundation for building more secure password management systems.
